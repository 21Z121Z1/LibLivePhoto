# Technical writing

Use ASD-STE100 Issue 9 principles for English technical documentation.
Use one approved term for each concept. Define a term before its first use.
State requirements with **must**. State recommendations with **should**.
Use active voice and short sentences. Give each sentence one technical purpose.
Label standard requirements, vendor behavior, observations, inferences and hypotheses.
State the test and its evidence layer with each support claim.
Do not call output lossless without byte or sample comparison evidence.
Chinese documentation uses the same information discipline. It does not claim STE compliance.

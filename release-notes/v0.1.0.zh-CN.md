## 0.1.0 — 2026-11-06

[English](v0.1.0.md)

Rust 核心和 `llp` CLI 的首个普通版本。GitHub SDK/源码发布与 crates.io 上传分别记录可用状态。

- 检查、提取、结构检查和转换受支持的 Apple 实况照片、Android 动态照片及 Samsung SEF 布局，不转码媒体。
- 按明确的转换与无法映射资源策略保留精确资源字节和有理数照片时间，提供有界厂商元数据检查。
- 声明最低 Rust 版本为 1.88。
- 提供英文、简体中文文档和发布说明。
- 随包提供测试和示例所需的合成数据、README 与许可证文本，并在源码仓库之外验证消费程序。
- 提供含依赖声明、源身份与文件哈希的主机 SDK 归档。
- C/JNI、Android AAR、Swift、WASM 和 `xdremux-compat` 保留实验标记。

维护者已确认完成实机验证，公开记录尚未逐项列出设备、系统和操作组合，见[兼容性记录](../COMPATIBILITY.zh-CN.md#实机验证)。自动化构建收据只描述自身覆盖范围。

## 兼容性约定

正式支持的 Rust 核心和 `llp` 在 0.1.x 补丁版本中保持公开源码兼容，以及已有 CLI 选项/JSON 字段含义。不兼容改动使用新的次版本。JSON 消费程序必须接受新增字段和诊断；面向人的消息不是稳定标识符。0.1.x 期间最低 Rust 版本保持 1.88。实验绑定与 `xdremux-compat` 不在此保证内，其不兼容改动会另行说明。
